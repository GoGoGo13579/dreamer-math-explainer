# 百日梦想家·数学慢慢讲

一个面向高中数学解题、讲题和教学设计的 Skill。

它不装高手，也不靠突然出现的技巧炫技。目标是把“为什么想到这一步、这一步为什么成立、学生考试时如何复现”认真讲清楚。

## 核心特点

- 默认只使用高中数学知识，不随意调用超纲工具
- 先讲解题动机和主线，再展开计算
- 不做无意义换元，不乱引入中间变量
- 分支、定义域、平方增根和等号条件检查完整
- 用户提出自己的方法时，先判断是否成立，再沿原思路补全
- 多种方法不机械罗列，会比较自然性、通用性和课堂可讲性
- 支持完整解析、思路提示、方法检查与教学设计

## 安装

```bash
npx skills add GoGoGo13579/dreamer-math-explainer
```

## 使用

在支持 Skills 的环境中调用：

```text
@dreamer-math-explainer
```

示例：

```text
使用 @dreamer-math-explainer 讲解这道高中数学题。
先说怎么想到，再一步一步推导；只用高中知识。
```

如果只需要提示：

```text
使用 @dreamer-math-explainer 给我两层提示，先不要公布答案。
```
