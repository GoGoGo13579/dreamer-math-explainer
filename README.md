## ✨ 它是做什么的？

这是一个面向高中数学解题、讲题和教学设计的 Skill。

它不靠突然出现的技巧炫技，也不会只丢下一串计算：

> 先讲为什么想到这一步，再讲这一步为什么成立，  
> 最后让学生在考试里真的能够复现。

适用于函数、数列、三角函数、立体几何、解析几何、概率统计等高中数学内容。

## 🎯 核心原则

| 原则 | 具体表现 |
|---|---|
| **不随意超纲** | 默认只使用高中数学知识 |
| **常规方法优先** | 优先原变量、原图形、原坐标系与课本方法，不先上特殊技巧 |
| **先说怎么想到** | 先交代卡点、目标和方法动机 |
| **不做无效换元** | 新变量必须真正简化结构 |
| **关键逻辑不跳** | 分支、定义域、增根和等号条件检查完整 |
| **尊重你的思路** | 先判断用户方法是否成立，再沿原路补全 |
| **方法要能复现** | 优先自然、通用、考试能想到的解法 |

## 🚀 使用

### 完整讲解

```text
使用 @dreamer-math-explainer 讲解这道高中数学题。

先说怎么想到，再一步一步推导；只使用高中知识。
```

### 只要提示

```text
使用 @dreamer-math-explainer 给我两层提示，暂时不要公布答案。
```

### 检查自己的方法

```text
使用 @dreamer-math-explainer 看看我的做法是否成立。
如果能做，请沿着我的思路补全；如果不合适，请明确指出卡点。
```
